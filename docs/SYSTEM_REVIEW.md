# System review

**Reviewed:** 24 November 2026
**Scope:** repository, product flows, automated tests/build, production HTTP and MCP behavior, and recent Vercel runtime error clusters.  
**Status:** active review snapshot; this is not a security certification or a claim that every roadmap item is complete.

## Current assessment

The core interview lifecycle is in good shape for bounded, host-run questionnaire collection. The app validates questionnaires, isolates respondent links, retains recoverable drafts, supports routing and repeat records, separates respondent-level analytics from repeat rows, offers multiple export formats, and protects MCP operations with credential-scoped capabilities. The automated suite and production build are healthy.

The largest remaining risks are operational durability and scale: outbound mail can have an ambiguous result after a provider accepts it, individual respondent payloads can grow with questionnaire size, and buffered export formats remain in-memory and capped. By product direction, the app does not collect consent acknowledgements or present workspace-authored respondent notices; retention and withdrawal remain external workflows. The new questionnaire composer covers common scalar and repeat-group authoring, bounded all-match/any-match routing, nominal choice rotation with fixed positions, exclusive multi-choice options, and opt-in question-order groups; stable-ID editing of existing versions and scheduled campaign tools remain meaningful adoption improvements.
